# f-stats

Личный сайт со следующими турами АПЛ, Ла Лиги, Серии А, Бундеслиги, Лиги 1,
Лиги чемпионов и Лиги Европы и статистикой команд за последние 3 месяца.

- `index.html` — сайт (GitHub Pages).
- `scripts/update.py` — загрузчик данных с FotMob, запускается каждый час
  через GitHub Actions (`.github/workflows/update.yml`).
- `data/matches.json` — сыгранные матчи со статистикой по таймам (старше 90 дней удаляются).
- `data/meta.json` — команды, таблицы, ближайшие туры.

Обновить данные вручную: Actions → «Обновление данных» → Run workflow.
