# Как работать с проектом через ChatGPT

Сайт и данные обновляются сами на GitHub, ИИ для этого не нужен. ChatGPT нужен для трёх вещей:
описания ставок, сбор экспрессов и раз в 1–2 месяца — проверка модели по журналу.

---

## Шаг 0. Один раз: создать проект в ChatGPT

ChatGPT → «Проекты» → «Новый проект» → назвать «Ставки f-stats».

1. В **инструкции проекта** вставить блок из раздела «Текст для инструкций» ниже.
2. В **файлы проекта** загрузить `HANDOVER.md` и этот файл (`GPT_INSTRUCTIONS.md`).

## Как дать ChatGPT свежие данные

Перед каждым разговором (данные меняются каждый час):

1. (Если нужны свежие кэфы) GitHub → репозиторий f-stats → Actions → «Обновление данных» →
   Run workflow → подождать 3–5 минут до зелёной галочки.
2. Скачать архив: https://github.com/mikhaillukovtsev/f-stats/archive/refs/heads/main.zip
3. Загрузить этот zip в чат ChatGPT вместе с вопросом или скрином.

ChatGPT сам распакует архив и запустит готовые скрипты (у него есть Python).

## Текст для инструкций проекта (скопировать целиком)

```
Ты помогаешь мне с футбольными ставками для теста в Telegram-канале. Ставлю только в Фонбете/Пари
(кэфы там одинаковые). Правила теста: только футбол, кэфы примерно 1.7–2.1 (мини-экспрессы из
2 событий 1.6–1.9), качество важнее количества.

Мой проект описан в файле HANDOVER.md — прочитай его. Когда я присылаю zip-архив f-stats-main.zip,
распакуй его и работай с данными из папки data/:
- описание ставки: python scripts/match_report.py "Команда1" "Команда2" ["слово из ставки"]
  (названия английские, как на сайте; можно часть названия). Скрипт выдаёт оценки сайта по всем
  ставкам матча и последние матчи обеих команд (голы по таймам, угловые, ЖК).
- проверка модели: python scripts/analyze_log.py data/log/settled-*.jsonl

Описания ставок пиши СТРОГО в формате (без лишнего текста внутри блока):

DD.MM
N)Команда – Команда(Лига)

X.XX - Ставка

2–3 предложения обоснования на русском, с конкретными цифрами из последних матчей.

Для экспресса: несколько строк N)Команда – Команда(Лига), потом одна строка
"X.XX - Ставка + Ставка" и 2–3 предложения.
Команды и лиги пиши по-русски (Интер – Комо(Серия А), Лига чемпионов, Лига наций и т.д.).

После блока отдельно и коротко дай честное мнение: шанс по модели/фактам/рынку,
справедливый кэф, перевес и главный риск. Если перевеса нет или он отрицательный — прямо скажи
и предложи пропустить. Не подгоняй анализ под ставку. Помни: по журналу рынок Фонбета пока
точнее модели сайта, поэтому большие «перевесы» (больше 15–20%) скорее ошибка модели.

Тон: коротко, по делу, по-русски.
```

## Типовые задачи

**Описание ставки по скрину.** Прислать zip + скрин купона:
«Дай описание». ChatGPT найдёт матч через `match_report.py` и напишет пост.

**Мини-экспрессы на день.** Прислать zip:
«Собери N мини-экспрессов из 2 событий на кэф 1.6–1.9 на сегодня, ставки не повторять».
Логика, которой я пользовался: из `data/value.json` берутся матчи сегодня, ставки с
`ev > 0.02`, без возврата (`push < 0.01`), модель и факты согласны (`agree == true`),
кэф 1.15–1.65; пары из разных матчей с произведением кэфов 1.6–1.9; сортировка по шансу `p`.
Обязательно предупреждать, если один матч стоит в нескольких экспрессах.

**Сборные/матчи, которых нет на сайте.** ChatGPT ищет статистику в интернете и честно пишет,
что модель сайта этот матч не считает.

## Проверка модели раз в 1–2 месяца

Прислать zip: «Запусти scripts/analyze_log.py по всем settled-файлам и объясни результат».

Что смотреть:
- **Brier**: если колонка «модель» стала меньше колонки «рынок» хоть в одном виде ставок —
  в этом виде модель обыгрывает Фонбет. Это главное, что мы ищем.
- **Лучший вес рынка (MARKET_W)**: на 19.11.2026 везде 1.0 (рынок лучше модели).
  Если где-то станет 0.5–0.7 — модель начала приносить пользу.
- **ROI ставок с перевесом** и **«кэф первый/закрытие»**: плюс во втором столбце значит, что
  после нашей находки кэф падал (линия за нас) — главный признак настоящего перевеса.
  На 19.11.2026: всё в минусе, кроме ЖК (+11% ROI на 38 ставках — слишком мало, надо копить).

Как поменять вес рынка, если решите: GitHub → `scripts/value.py` → карандаш (Edit) →
строка `MARKET_W = 0.5` → новое число → Commit changes. Сайт пересчитается сам за 5 минут.

## Если что-то сломалось

GitHub → Actions → последний запуск «Обновление данных» → открыть красный шаг → скопировать
текст ошибки в ChatGPT вместе с zip-архивом. Самые частые причины:
- FotMob или Фонбет поменяли адрес/формат — правится в `scripts/update.py` / `scripts/odds.py`;
- новая команда с русским названием не сопоставилась — добавить в `ALIAS` в `scripts/value.py`.

Учёт ставок на сайте хранится в браузере: вкладка «Учёт» → «Перенос на другое устройство» —
сохрани код в заметках, чтобы не потерять.
